## 体验与来源流程

- 对照 Animeko、Miru 等官方界面/源码，首页改为真实 Bangumi 放送表、作品封面和本地在看状态；没有加入用户拒绝的 AI 插图。
- 封面和标题本身可点击。元数据、封面、本地数据和资源加载分别呈现，不让本地数据库等待挡住已选作品首屏。
- 增加来源直接搜索，允许不依赖 Bangumi 条目找到来源作品。
- 小说、漫画先确认准确来源对象再列分卷/章节；修复卷名、简繁与逗号别名，降权同人、插画集、音乐、宣传片及合集。
- 动画检索优先轻量 RSS，核对剧目与 Bangumi ID，季/集范围有警示；不把一千条关键词结果全摊为同一作品的有效资源。
- 来源需用户明确启用，可在作品/来源搜索流程中操作；没有预置无关开源样片冒充用户要找的内容。

研究与实测依据见 [product-ui-study.md](product-ui-study.md)、[real-workflow-audit.md](real-workflow-audit.md)、[native-network-study.md](native-network-study.md)。

## 下载能力的实际变化

普通 HTTP 和默认 BT 可由内置 aria2 接收，qBittorrent 是可选项；Torrent 元数据任务需要跟随真实内容任务。它们是实现能力，不保证特定公网种子有连接。
