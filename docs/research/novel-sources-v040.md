# 0.4.0 轻小说来源与正文链路核查

核查日期：2026-10-31。本轮保留原有动画、漫画来源，轻小说以 LNovel 的中文日轻文本为主。探测使用普通公开 HTTPS 请求，没有使用账号、Cookie、Token 或验证码处理。

## 首屏与正篇漏检修复

轻小说首页使用 Bangumi 作品资料，先显示首批 8 部真实推荐，再补齐本页 24 部。已有过期缓存先显示并在后台刷新；第二批请求失败时保留已显示内容，提供「补全本页」重试。作品发现与正文下载是两个独立流程，首页出现作品不代表下载来源提供完整正文。

LNovel 的物化缓存目录漏掉正篇时，现在补查官方月 / 周索引并按作品 ID 合并，不只依赖已缓存的衍生作品。《无职转生》正篇 2013 与蛇足篇 4325 分别保留。实际正篇详情 API 返回 HTTP 408，序章错误响应表示作品和章节已下架；本轮没有取得正篇完整首卷。完整请求、原站截断正文及处理边界见[正篇专项核查](lnovel-main-series-v040.md)。

## LNovel 真实样本

| 来源 | 本次实测 | 适用范围与限制 |
| --- | --- | --- |
| [LNovel](https://lnovel.animes.garden/) | 精确搜索《文学少女》得到 nid 88、20 卷；第一卷 10 个目录项逐项读取，生成 83,192 字符的 UTF-8 TXT，其中 68,233 个汉字；现有阅读器解析出序章、正文和后记目录。作者“野村美月”检索返回《文学少女》《审稿男孩和投稿女孩》2 部作品 | 中文日轻文本主源。`/api/bili/novels` 在核查时有 772 部已缓存作品，**并非原站全部作品**。可粘贴来源支持的作品网址或站点 ID 补查；能否即时获取、何时更新取决于上游。TXT 不含插图 |

本样本共记录 **13 次 LNovel HTTP 请求**：缓存作品目录、作品详情、第一卷目录各 1 次，以及 10 个章节项；这 13 次响应均为 HTTP 200。20 卷是本次列出的目录数量，本轮只逐项读取并生成第一卷，没有将全部目录计为已下载。

完整 TXT 仅保存在本机 `.work/novel-sources-v040/lnovel-first-volume.txt`，不加入仓库。输出 SHA-256 为 `bbecc758d436bbb17bd23825f8a81a796a49f88c83d65f074f612149091d8ace`。文字数与目录项数属于这一个样本，不代表来源覆盖率或翻译质量。

## 已修复的问题

- 原来只匹配作品名，输入作者没有返回其作品。现在按正式作者署名精确匹配，返回结构化作者字段；不会因简介提到某人而命中，也不会把插画师当作小说作者。
- 中文短书名允许两字匹配；拉丁短词及其它媒体来源继续使用各自原规则。
- 可直接识别站点 ID 及支持的作品网址，避免必须先在上游缓存目录中找到作品。直接补查仍可能因上游无数据、超时或验证要求而失败。
- 有图片列表、没有文字的章节在 TXT 中保留插图缺失提示，避免有插图的普通小说整卷失败；全卷没有可用正文时仍拒绝生成空 TXT。
- HTML 转纯文本先移除实际标签，再解码实体，保留 `&lt;…&gt;` 形式的正常文字与行内文字顺序；清除脚本内容，非法数字实体不使整卷异常。
- 校验作品、卷和章节所属 ID，拒绝跨书、跨卷及重复章节。缓存卷目录和章节，减少准备下载后的重复请求，以及失败重试时重复读取已完成正文。

LNovel 官方项目当前服务端提供 `bili` 小说正文命名空间。项目 README 提到轻小说文库，不代表现有部署仍有可用 `/api/wenku/novels`；该路径探测返回 404，没有据此添加第二条 API。日轻补充源需分别核对文本语言、作品身份及实际正文，当前产品文案仅列已经接入的能力。

## 验证与证据边界

生产适配器通过 Vite SSR 加载，注入记录真实网络响应的普通 HTTP transport。一个 LNovel 文本卷经生产下载逻辑生成，写入仅允许 `.work/novel-sources-v040/` 的 Node 文件测试适配器，再使用生产 `parseNovelText` 解析。**这验证真实来源到 TXT 内容生成与目录解析的链路，不等同于原生桌面 UI 的端到端验收。**

- 仅含该来源的概要、URL、状态码、响应大小、耗时和 SHA-256 摘录：`.work/novel-sources-v040/lnovel-live-verification.json`。13 次请求按 LNovel 主机筛选，未沿用其它探测的合计数量。
- LNovel 回归用例位于 `src/tests/lnovel-source-provider.test.ts`，覆盖作者匹配、短书名、直接 ID、存储资源重建、空卷、图片项、正文解码和跨书身份校验。全量测试状态以项目 `VERIFICATION.md` 为准。
- 本地记录与完整小说文本不随源码或安装包分发；来源可用性只对应核查时的具体响应。
