# 0.5.3 中文轻小说来源核查

核查日期：2026-11-02。重点是可实际下载的中文轻小说正文、插图和分卷目录，不以网站首页正常或搜索有结果代替成品验证。本轮仅使用匿名公开 HTTP 请求；没有导入用户 Cookie、登录账户或触发代建电子书的 GitHub Issue，也没有绕过验证码、付费或版权下架标记。

## 接入来源与结论

[mojimoon/wenku8](https://github.com/mojimoon/wenku8) 是第三方社区维护的轻小说电子书目录与生成项目，项目代码使用 [MIT 许可证](https://github.com/mojimoon/wenku8/blob/main/LICENSE)。它不是出版社或 Bangumi 官方下载服务。ACGN Hub 本轮独立实现协议适配，没有复制该项目的爬虫或登录代码，也没有将小说全文、插图或 EPUB 文件提交到本仓库。

生产适配器只读取 [公开 EPUB 索引](https://raw.githubusercontent.com/mojimoon/wenku8/main/out/epub_index.json) 中已经生成的按卷附件，从对应 GitHub Release 下载完整 EPUB。普通访问 [轻小说文库原站](https://www.wenku8.net/) 本次返回 HTTP 403；这个状态没有被伪装成可直接读取章节，也没有实施挑战绕过。[社区目录网页](https://wenku.mojimoon.top/) 则返回 HTTP 200。

本次索引为单个 UTF-8 JSON 文件，无网络分页，大小 **1,230,501 字节**，SHA-256 为 `7a66ee09df9d12b9bd79c4db7c95306bc079641289761366398ed0c2afd77181`。它包含 **2,209** 个作品条目，其中 **2,112** 部在默认版或其他清晰度版本中有已生成分卷，**97** 部被上游标记为版权下架。20 部作品另有清晰度版本，9 部只有清晰度版本而没有默认版；如果只读取顶层 `volumes`，会漏掉这 9 部作品。

这些数目仅代表核查时索引收录；没有逐一验证两千余部作品的全部附件，更不能称为全站或全系列完整覆盖。

[项目说明](https://github.com/mojimoon/wenku8/blob/main/README.md) 表示生成器支持默认、原图和多种插图尺寸。默认尺寸说明不能替代实际文件尺寸，本次《文学少女》默认附件就包含长边 1600 的图片。ACGN Hub 保留下载到的 EPUB 字节，不再压缩或放大图片；`orig` 表示来源声明的原图版，不代表本应用核验过出版社原始扫描。其他作品的图像、缺章和校对质量仍取决于上游，不能用两个样本证明全部完美。

## 适配规则

- 新来源类型 `wenku8_epub`，默认地址 `https://raw.githubusercontent.com/mojimoon/wenku8/main`；请求路径为 `/out/epub_index.json`。默认不启用，用户可在来源管理或资源搜索中选择。
- 支持书名、别名和正式作者名检索；作者姓名支持已有的有限简繁变体规则。本次实际搜索“入間人間”返回 **26** 部该作者作品，不返回人物卡片。结果每页 40 条，避免适配器只保留前 12 部。
- 目录缓存 15 分钟，并合并同时发生的加载；健康检查刷新索引。失败不写入缓存，重试无需重启。目录连接成功只表示索引可读，健康提示不宣称每个附件已验证。
- 每卷优先选择索引里已生成的 `orig`、1600、1400、默认/1000、800、600、无图版本；高质量版本没有某一卷时仍保留默认版的该卷，不生成重复卷。
- 资源身份包含作品 ID、卷顺序以及非默认质量后缀。重新打开时依据当前目录重建地址，既不信任数据库中的任意下载地址，也不会把已经选择的默认/1600 文件静默切换成后加入的原图文件。
- 分卷 `volumeOrder` 是目录顺序，不能把它强行解释为“第几卷”的书名数字；原始卷名独立保留。资源另带章数、插图数、源更新日期、生成日期，供界面和内置阅读器使用。
- 下载文件名包含中文书名和卷名；非默认版本加“原图版”“插图1600px”等后缀，保持 `.epub` 扩展名并区分已有的不同质量文件。
- 校验目录作品 ID、`book-{aid}` tag、卷顺序、附件名、正数大小和章节数；拒绝重复卷身份、路径穿越、错作品 tag 及格式异常。下架原作候选明确显示状态，点击时拒绝生成资源；未生成条目也不产生空 EPUB。
- 不为新来源额外请求作品封面或原站详情，以免目录可读而封面站失败拖住作品选择。

## 验证边界与证据

完整文件和原始请求只保存在本机忽略目录 `.work/sources-v053/novels`。其中 `provider-audit.json` 记录生产适配器的真实网络搜索、目录、作者、质量选择和下载摘要；`1-v01-verification.json`（早期同内容文件名为 `epub-verification.json`）与 `3019-orig-v01-verification.json` 记录 ZIP、OPF、spine 文字数量及完整图片解码结果。`audit-provider.mjs` 可复核实际生产适配器请求；没有通过模拟正文伪造成品。

`src/tests/wenku8-source-provider.test.ts` 验证目录解析、作者分页、最高可用质量、只有变体的作品、不同质量文件身份、冷恢复、缓存与重试、下架拒绝和恶意/混乱目录。`tests/e2e/wenku8-source-workflow.spec.ts` 使用固定公开 HTTP 契约验证来源选择、作品选择、按卷展示、下载排队和重新打开；这些浏览器契约测试不等同于原生 Windows/Android 成品验收。

索引项目核查时 main commit 为 `34bd57d810c7ac9a3714bf767dd22f79db9dae65`。目录和附件由外部维护，可能更新、删除或受当前网络影响；本应用不对源站访问限制做安全设置修改。
