# 0.4.0 轻小说检索与《无职转生》核查

核查日期：2026-10-31。用户指定的目标是《无职转生》正篇。本轮区分了软件漏检、目录可见和正文能否完整取得，没有把蛇足篇或截断文字代替正篇成品。

## 原作漏检的根因与修复

旧适配器只查询 LNovel 的 `GET /api/bili/novels`。这个接口返回已经物化的作品缓存，并不是原站完整书目：当次返回了 **4325《无职转生 ～蛇足篇～》**，没有 **2013《无职转生 ～到了异世界就拿出真本事～》**。

但是原站公开的月点击榜、周点击榜都明确列出正篇 2013，作者同为“理不尽な孙の手”。因此“搜不到正篇”包含真实的软件检索缺陷，不能仅解释为来源没有这本书。

现已加入通用补查：缓存目录没有匹配，或只匹配到衍生作品时，并行读取官方周/月榜索引，按作品 ID 合并去重，再按作品名和正式作者署名匹配。没有硬编码《无职转生》或 2013。榜单补查有短期缓存，单个索引失败不会抹掉其它已返回作品。

2026-10-31 21:22（Asia/Shanghai）生产 provider 的真实 HTTPS 搜索结果，顺序为：

1. 2013《无职转生 ～到了异世界就拿出真本事～》：来自公开榜单，明确提示章节缓存未收录、目录与正文需另行核实。
2. 4325《无职转生 ～蛇足篇～》：独立保留为衍生作品，不自动充当正篇。

上述目录、月榜、周榜三次请求均返回 HTTP 200。该补查扩大了能被发现的真实作品范围，仍不能宣称覆盖原站全集。

## 正篇当前下载状态

搜索中能确认正篇存在，不等于当前来源能提供完整正文。此次实际核验得到：

| 请求 | 实测结果 | 应用处理 |
| --- | --- | --- |
| LNovel 正篇详情 `/api/bili/novel/2013` | 上游返回 HTTP 408 | 提示作品索引存在，但来源当前无法取得未缓存的目录或正文 |
| LNovel 正篇序章 `/api/bili/novel/2013/chapter/72034` | HTTP 500；公开错误响应明确表示该作品和章节已下架 | 明确提示来源已下架此作品或章节，不输出上游调用细节 |
| LNovel 文库索引补查 | 上游报告未缓存内容抓取暂时停用 | 显示来源现取不可用，保留可用的已缓存作品 |
| 原站繁体详情、作品目录、首卷目录 | 普通匿名 HTTPS 可访问，确认正篇、首卷 72033《1 幼年期》及 20 个目录项 | 仅作为作品和目录的旁证，没有据此宣称整卷可下 |
| 原站繁体序章及另一正文首屏 | 返回截断片段及明确的内容加载失败提示；普通移动端请求仍相同，部分后续分页可读 | 没有拼接或删除失败提示伪造完整章节，没有加入未经验证的正文回退 |

**本轮未取得正篇完整首卷，不能保证此作品当前可下载。** 也没有绕过原站挑战、登录、付费或下架状态。此前缓存覆盖不足造成的漏检已经修复；当前正篇正文不可取的情况同时保留为来源限制。

## 保留并验证的轻小说正文功能

LNovel 中文日轻下载继续保留。此前本轮以《文学少女》nid 88、首卷 vid 12411 的 10 个目录项逐项读取，生成 UTF-8 TXT：83,192 个字符、68,233 个汉字。生产阅读器解析出序章、正文与后记等 7 个目录标题，原始目录里的插图及其它非标准标题没有被虚构成正文标题。

正文文件仅存本机 `.work`，没有上传仓库。该实测使用生产 provider、真实章节请求和只允许写入测试目录的 Node 文件适配器，证明来源读取、完整 TXT 内容生成及阅读器解析；不能代替原生桌面 UI 端到端验收。

其余保留修复包括正式作者的简繁姓名精确匹配、中文两字书名检索、转义文本保留、非法数字实体处理、插图项明确占位、跨作品与跨卷校验、重复章节防护，以及准备与下载间的缓存复用。没有加入用户不需要的中文原创平台。

## 回归与证据

- `src/tests/lnovel-source-provider.test.ts`：14 项定向测试通过。覆盖缓存仅有衍生篇时发现真实正篇、周/月榜去重缓存、正式作者姓名变体、索引部分失败、图片章节、正文身份校验、实体解码、下架提示、上游抓取停用和非 JSON 的 HTTP 408。作品、分卷、章节自身的 `isDeleted` 标记单独报告下架，不再误报为其它作品。
- 最终真实搜索与既有成品核验：`.work/novel-sources-v040/mushoku-final-verification.json`，保留 URL、状态码、大小、耗时、SHA-256、候选及正文成品摘要。
- 早期目录、榜单、下架和截断正文证据均保留在同目录；全文与私人测试产物不入库。
