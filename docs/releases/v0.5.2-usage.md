# ACGN Hub 0.5.2 使用指南

本指南说明0.5.2的流程修复与升级方式。安装文件、SHA256和正式发布状态以 [GitHub Releases](https://github.com/CidneyAurum/ACGN-Hub/releases/latest) 实际附件为准。

## 安装与升级

| 平台 | 推荐文件 | 要求 |
| --- | --- | --- |
| Windows | `ACGN-Hub-0.5.2-windows-x64-portable.zip`，另提供EXE / x64 setup | Windows x64、Microsoft Edge WebView2 Runtime |
| Android | `ACGN-Hub-0.5.2-android-64bit.apk` | Android 8.0 / API26+，arm64-v8a或x86_64 |

Windows完整解压后运行 `START-PORTABLE.cmd`，保留程序、`ACGN-HUB-PORTABLE`标记和配套文件。升级前完全关闭应用，备份旧目录，将原 `Data` 复制到新版独立目录；不要合并两个已有资料库或同时运行两个实例写同一份 `Data`。

Android优先使用同包名、同签名覆盖安装。卸载会删除应用私有资料及成品，重要文件先导出；系统最低版本不等于WebView引擎版本，建议保持Android System WebView / Chrome更新。Windows与Android暂不自动同步收藏、文件和进度。

## 本版修复

- **资源搜索与选择**：结果绑定提交时的作品名、分类和来源。修改查询后清除旧候选，选择期间拒绝重复提交，避免旧作品被配上新查询或重复进入详情。
- **收藏与来源初始化**：保存操作等待原始读取完成，避免慢加载随后覆盖刚保存的收藏、来源配置或启用状态。
- **Android失效任务句柄**：恢复下载时即使还没轮询状态，也能识别确切的“没有找到安卓下载记录”并重新提交。权限、损坏及其他错误保留原句柄，不当作丢失任务重复下载；取消确实已丢失的任务可以正常结束本地记录。
- **元数据请求生命周期**：原生JSON请求即使没有调用方取消信号，也有默认10秒等待上限；自定义值限定500–35000毫秒。保留调用方取消原因并清理兼容计时器 / 监听，响应读取或连接错误不再一律说成无效JSON，只有语法解析错误才归入该类。

这些修改处理本地状态和请求生命周期，**没有重构网络出口，也不解决地区、运营商或节点访问限制**。来源可访问与具体资源可下载仍取决于原站及当前网络。

## 下载与阅读

Windows使用内置aria2处理HTTP、磁力和Torrent，qBittorrent可选。Android使用前台HTTP引擎和私有目录，支持来源可读取的CBZ / TXT下载及内读；不运行BT、Python工具或Windows游戏。下载时保持应用运行，不承诺锁屏或后台持续传输。HTTP进程重启后任务以暂停恢复，实际续传取决于服务器；CBZ / TXT生成不承诺逐页 / 逐章跨进程续传。

漫画支持连续长滚、单页和全屏，小说支持目录、阅读设置与进度。自动接续只进入同作品同版且已完成的下一话 / 卷，可取消，不自动下载缺少内容。系统「导出 / 分享」由用户选择目标，取消不发送文件；EPUB / PDF需外部应用，视频兼容性取决于系统编码。

本版不新增菠萝包或变更现有来源范围。此前安装和功能背景见 [0.5.1 指南](v0.5.1-usage.md)，本次红绿、产物身份和验收范围见 [0.5.2 修复记录](../research/bugfixes-v052.md)。
