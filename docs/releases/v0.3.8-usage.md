# ACGN Hub 0.3.8 · Galgame 完整资源与文件下载

打开“发现 → Galgame”，在精选作品下方选择：

- **真红小站 · 游戏文件**：匿名检索原站压缩包目录。选择准确版本后，文件直链可以加入内置下载器。已核对 CLANNAD 官中、ATRI、千恋万花官中、Summer Pockets 汉化版本的真实目录与独立文件详情。部分下载请求支持 Range，实际断点与速度以下载时的引擎探测为准。
- **ShionLib · 游戏资源库**：查看不同译本、汉化组、免安装／安装版本、平台、容量和文件清单。按条目打开准确资源页，在原站完成人机验证后获取实际文件链接；可复制链接到下载中心。显示的哈希为原站记录，不代表已经校验本地文件。
- **鲲 Galgame**：作为社区发布和不同平台的补充；网盘、商店、官网按外链打开。

“资源搜索”支持同时查找全部已启用来源，某一来源失败时仍显示其它来源结果。新源以停用可选项提供，选择后点击“启用此来源并搜索”才保存。已有的地址、凭据与启用状态不会被重置。

详情资源可组合选择“中文、Windows、游戏本体、文件直链”，文字筛选支持用空格同时输入多个条件。不明语言／平台不会被当作中文 Windows，本体、试玩、独立补丁、原声和混包分别标识；已集成补丁的完整游戏仍按本体显示。

同一作品不同版本可用版本下拉区分。“全选／下载所选”只操作当前显示版本；同名档案按作品、来源和版本建立独立子目录。分卷放在同一个目录并保留完整后缀，请下载全部分卷后再解压。下载归档不等于安装游戏，解压后可在 Galgame 管理中扫描实际安装目录。

官方发行、试玩和免费小品保留在折叠参考区。VNDB 中文完整版优先，不再将试玩排到相同语言的完整版前面。
