# ACGN Hub 0.5.1 使用指南

本指南说明 0.5.1 的兼容修复、下载阅读功能与升级方式。安装文件、校验值和最终发布状态以 [GitHub Releases](https://github.com/CidneyAurum/ACGN-Hub/releases/latest) 实际附件为准；各轮验证保留自身版本身份。

## 安装与保留资料

| 平台 | 文件 | 要求 |
| --- | --- | --- |
| Windows | `ACGN-Hub-0.5.1-windows-x64-portable.zip`、EXE 或 x64 setup | Windows x64，Microsoft Edge WebView2 Runtime |
| Android | `ACGN-Hub-0.5.1-android-64bit.apk` | Android 8.0 / API 26 及以上，arm64-v8a 或 x86_64 |

Windows 便携版完整解压后运行 `START-PORTABLE.cmd`，保留 EXE、`ACGN-HUB-PORTABLE` 标记和配套文件。升级前关闭应用并备份旧目录，再将原 `Data` 复制到新版独立目录；不要合并覆盖两个已有资料库，也不要让两个实例同时写入同一个 `Data`。

Android 优先覆盖安装同包名、同签名的新版以保留资料。卸载会删除应用私有资料与成品，重要文件先通过下载记录中的「导出 / 分享」交给所选应用。系统最低版本与 WebView 引擎版本不同；请使用设备可获取的新版 Android System WebView / Chrome。本版兼容修复和 Chrome 87 构建目标不代表所有 Android 8 手机或厂商 WebView 都已实测。

## 本版修复

- 旧 WebView 缺少 `structuredClone`、AbortSignal 超时 / 合并 / 取消方法、`Array.at`、`Object.hasOwn` 等 API 时，避免接口成功后仍在缓存、作者搜索或来源处理中失败；不修改系统环境，不全局替换浏览器 API。
- Android HTTP 更严格核对 Range、实体标识与响应长度，拒绝错误续传和超出声明范围的内容；完善完成发布恢复和取消边界。
- 下载刚完成时再点击暂停 / 取消，不把完成成品误记为取消；刷新后保留完成结果。
- 阅读器修复短末章目录回退、短横向漫画末页页码 / 接续失效；小说在全屏切换或视口变化时保留阅读比例。
- 来源检查区分可识别的 DNS、TLS、连接、读取、超时和 HTTP 状态；异步检查不覆盖期间修改的启用状态或新地址。

## 手机显示来源连接失败时

先在手机浏览器打开来源的公开主页和当前 RSS 地址，例如 `https://mikanani.me/`、`https://mikanani.me/RSS/Classic`，记录能否加载及具体错误，再对照应用「来源管理 → 检查连接」的结果。比较同一部手机的 Wi-Fi 与移动数据结果有助于区分设备、网络和来源限制；不需要提供账号、Cookie、Token 或私有订阅链接。

排查时保留这几项即可：手机型号、Android 版本、WebView / Chrome 版本、使用的网络类型、应用内错误原文及浏览器对公开地址的访问结果。浏览器成功不自动证明应用原生网络成功；电脑 HTTP 200 也不证明手机的 5G / Wi-Fi 能访问同一地址。只显示通用网络失败时，不凭空认定是 DNS、TLS 或来源失效。

本轮已复现并修复缺失浏览器 API 导致的错误，但尚未取得反馈手机的设备型号、WebView 版本或浏览器访问结果，**不能认定该手机蜜柑失败的根因，也不宣称已经在该实体手机修好**。无需为排查关闭系统防护或安装未知证书。

## 下载与内置阅读

Windows 使用内置 aria2，支持普通 HTTP、磁力和 Torrent，qBittorrent 可选。Android 使用原生前台 HTTP 引擎和私有目录，支持来源可读取的 CBZ / TXT 下载与内读，不运行磁力 / Torrent、Python / JMComic / yt-dlp / FFmpeg 或 Windows 游戏。

Android 下载要求应用保持运行，不承诺锁屏 / 后台持续传输。原生 HTTP 任务进程重启后恢复为暂停，需手动继续，是否可续传取决于服务器；CBZ / TXT 生成不是同一套传输任务，不承诺逐页 / 逐章跨进程恢复。系统选择器由用户选择目标应用，取消不会发送文件；两平台不自动同步资料。

漫画可选连续长滚、单页和全屏；小说提供目录、字号、行距与纸色。自动接续只使用同作品、同版本且已完成的下一话 / 卷，可取消，不自动下载缺少的章节。EPUB / PDF 需外部应用；视频播放依赖系统编码。

本版未添加菠萝包。Bangumi / VNDB 提供作品资料，来源健康检查只说明当前访问结果，不保证某部作品或整个文件可下载。完整功能及迁移背景见 [0.5.0 指南](v0.5.0-usage.md)，本版测试红绿与原生范围见 [0.5.1 修复记录](../research/bugfixes-v051.md)。
