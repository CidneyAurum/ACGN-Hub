# ACGN Hub 0.3.7 · Galgame 发现与资源

发现页切换到 Galgame，可查看 VNDB 实时返回的中文可用佳作、近两年原作新作、真实封面、评分和收藏。列表会定时检查更新，也支持手动刷新与分页。近两年按原作首发日期筛选，不代表中文版本刚更新。

在作品详情点击“找资源”，或使用“资源搜索”并选择 Galgame：

- **鲲 Galgame**：中文社区资源索引，展示本体、补丁、平台、运行方式、体积及网盘名称。支持中文、原名、英文别名、作品 ID 和作品页链接。自动读取多页，上限 500 条目录记录；仅展示来源标记有效的条目，不代表已验证所有网盘文件。
- **VNDB · 官方发行与试玩**：匿名读取官方发行记录，中文、免费、试玩优先。区分完整发行、试玩、部分内容与补丁。官网和商店在浏览器打开，实际获取方式、价格、地区与权限以原站为准。原作可用中文不代表每个发行版本都有中文。
- 在 Galgame 发现页的资源指南中，已整理 ATRI 和千恋＊万花的官方中文试玩、Narcissu 与 DDLC 原版免费发行，以及 HIKARI FIELD 官方中文目录。
- **Narcissu 2nd 日文原版**提供原厂 HTTP 文件加入内置下载器。约 269 MiB，旧日文 Windows 版本，LZH 格式；需使用支持此格式的工具解压，再从 Galgame 管理中添加安装目录。没有把它标为中文或自动运行。

外链没有批量下载按钮，也不会作为文件交给下载器。需要下载游戏本体时，应核对资源类型，避免将补丁、试玩或原声当成完整游戏。

现有来源地址、凭据、启用状态与下载不重置。新来源以可选项提供，点击启用并搜索才保存。此前的漫画／TXT 内置阅读、自动接续、统一标题／作者作品搜索保持可用。

## 启动与数据

此目录的 START-PORTABLE.cmd 使用目录内独立的 Data。已有用户请继续使用工作区桌面快捷方式，其 START-ACGN-0.3.7.cmd 沿用原 release/v0.3.2/Data。不要将旧 Data 用新目录覆盖。所有旧版本保留。

## 验证范围

目录、发行、试玩和免费标记来自公开官方接口；社区资源的有效状态由原站声明。原厂 LZH 已验证 HTTP 206、文件容量与 LHA 文件头；没有声称完整下载、解压或运行游戏。商店入口不是文件直链。安装包未实际安装。详细验收见源码中的 VERIFICATION.md 与 docs/research/galgame-sources-2026-10.md。
