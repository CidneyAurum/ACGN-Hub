# ACGN Hub 0.5.3 使用指南

本版重点补充可实际下载的中文轻小说 EPUB 来源，并让 EPUB 在应用内保留正文、插图和分卷阅读。此文档当前为交付验收中的说明草稿，Windows、Android 原生验收和正式发布状态仍待补齐；可下载文件及 SHA-256 以 [GitHub Releases](https://github.com/CidneyAurum/ACGN-Hub/releases/latest) 正式附件为准。

## 安装与升级

| 平台 | 计划提供的文件 | 要求与当前状态 |
| --- | --- | --- |
| Windows | `ACGN-Hub-0.5.3-windows-x64-portable.zip`，另提供 EXE / x64 setup | Windows x64、Microsoft Edge WebView2 Runtime；本版原生成品待验收 |
| Android | `ACGN-Hub-0.5.3-android-64bit.apk` | Android 8.0 / API 26+，arm64-v8a 或 x86_64；本版 APK 待构建和原生验收 |

Windows 完整解压后运行 `START-PORTABLE.cmd`，保留程序、`ACGN-HUB-PORTABLE` 标记和配套文件。升级前完全退出应用并备份旧目录，将原 `Data` 复制到新版独立目录；不要合并两个已有资料库，或同时运行两个实例写同一份 `Data`。

Android 优先使用同包名、同签名覆盖安装。卸载会删除应用私有资料及成品，重要文件先导出。最低 Android 版本不代表 WebView 引擎版本，建议保持 Android System WebView / Chrome 更新。Windows 与 Android 暂不自动同步收藏、文件和进度。

## 轻小说 EPUB 来源

进入「找资源」→「小说」，选择 **Wenku8 · 插图 EPUB**，输入书名或作者，点击「启用此来源并搜索」。也可以在「管理我的来源」中启用。新来源默认关闭，不会重置已有来源地址、Token 或启用状态。

搜索作者会返回作者的作品。例如“入間人間”能够匹配“入间人间”的正式作者署名；选择具体作品后才显示该作品的分卷。作品名称、卷名、章节数和插图数分别展示，点击 **下载 EPUB** 下载该卷。文件名使用中文书名、卷名和必要的质量后缀，保留 `.epub` 扩展名。

此来源使用社区公开目录中已经生成的 EPUB 附件，下载需要能够访问 GitHub。它和 LNovel 是两个独立来源：**EPUB 可以包含插图，LNovel TXT 是纯文字**。两个来源的作品 ID、收录范围和更新进度不必相同。来源索引会定期重新读取，不把首次打开时的目录永久写死；上游尚未收录的内容不会自动出现在应用中。

同一卷存在多个已生成版本时，优先选择来源标记的原图版，然后是更高像素版本；高质量版缺少的卷可以使用已有默认版。保存的资源保留原选版本身份，重新打开不会把已选 1600px 文件静默换成另一版。应用保留来源 EPUB 的文件字节，不额外压缩或放大插图；“原图”是上游版本标记，不是本应用对出版社扫描质量的保证。

版权下架、尚未生成和真正可下的分卷会分别处理。例如《无职转生》正篇在本次核查的 EPUB 索引中明确被标记版权下架：应用保留原作名称并说明原因，不提供伪造下载，也不会用蛇足篇代替。索引正常表示可以查目录，不能保证每个外部附件始终可访问。

## EPUB 内置阅读

EPUB 下载完成后，在「下载」中点击阅读入口。内置阅读器依据电子书目录显示正文和插图，支持章节切换、滚动阅读、字号与行距调整、阅读宽度、纸张主题和进度保存。下载文件仍保留原 EPUB，可按需要导出或交给其他阅读器。

多卷作品按作品及卷顺序组织。自动接续只进入同作品、相应顺序且已经完成下载的下一卷，可以取消；不会自动下载缺失分卷。不同作品、不同改编或其他来源的同名作品不会仅凭文件名称相似就合并阅读进度。

有些 EPUB 本身没有插图，或卷内只有图片章节；展示效果取决于文件内容。损坏、不支持或受保护的文件应明确报告错误，不能把空白页当成正常读完。本版 EPUB 图文内读的 Windows、Android 原生范围仍在交付验收中，下方验证状态会在正式发布前更新。

## 其他来源与修复

- **作者结果完整度**：LNovel 不再将匹配结果固定截在前 12 部，本轮扩展到与资源搜索一致的每页 40 条，按正式作者姓名匹配作品；这仍不代表来源收录了作者的全部作品。
- **Galgame 免费作品**：`itch.io · 官方免费精选`（接入和最终验收中）收录创作者免费发布的完整视觉小说，作为现有真红小站、ShionLib、KUN 和 VNDB 的补充。目前核查对象为支持简繁中文的 **one night, hot springs**、繁体中文的 **蝴蝶汤 Butterfly Soup**，以及目前仅确认英文的 **missed messages.**。精选目录不是 itch.io 全站搜索，也不代表所有商业作品都能免费下载。资源保留作者官网定位，实际下载时刷新有时效的文件地址；画集、付费包、补丁和试玩不作为完整游戏提供。Windows、Mac、Linux 或 Android 文件以各作品实际提供的平台为准，能下载不代表本机能够运行该平台游戏。
- **来源保存与升级**：来源类型的持久化与历史迁移使用同一份有效类型列表，修复新增来源无法启用，以及部分已有来源在升级导入时被遗漏的问题。

已有动画、漫画与 LNovel TXT 流程继续保留。Windows 使用内置 aria2 处理 HTTP、磁力和 Torrent，可选 qBittorrent；Android 使用前台 HTTP 下载，不运行 BT、Python 工具或 Windows 游戏。下载时保持应用运行，实际续传取决于服务器，不承诺锁屏或后台持续传输。

来源访问仍受原站、当前网络及地区限制影响。本版没有修改系统网络出口、安全设置或手机代理配置。
