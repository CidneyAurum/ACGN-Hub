# ACGN Hub 0.5.0 使用指南

本版将现有作品书架、资源检索、漫画与小说阅读适配到 Android，并保留 Windows 桌面下载与便携使用方式。

Windows 与 Android 构建、源码回归及原生样本验证已完成，本指南对应这组已验证产物。安装包和最终发布状态以 [GitHub Releases](https://github.com/CidneyAurum/ACGN-Hub/releases/latest) 的实际附件为准；下载后可核对 `RELEASE-ASSETS.json` 与 `CHECKSUMS-SHA256.txt`，具体样本及设备范围见[构建与验证记录](../research/android-v050.md)。

## 选择安装包

| 平台 | 目标产物 | 系统与架构 |
| --- | --- | --- |
| Windows | 便携 ZIP、EXE 与 NSIS 安装包 | Windows x64，需要 Microsoft Edge WebView2 Runtime |
| Android | 已签名 APK | Android 8.0 / API 26 及以上；包含 arm64-v8a 与 x86_64 |

普通使用无需安装开发工具。Android 不包含 32 位 ARM / x86 库，也不运行 Windows EXE。Android 最低版本是构建配置下限，本轮实际验收使用的系统版本将在发布记录中单独注明。

Windows 完整解压便携 ZIP 到可写目录，再运行 `START-PORTABLE.cmd`，或保留 `ACGN-HUB-PORTABLE` 标记后启动相邻 EXE。不要从压缩包预览中运行，也不要只取走 EXE。[0.4.0 使用指南](v0.4.0-usage.md#迁移与升级)中的完整目录备份、迁移与升级步骤继续适用。

Android 安装对应 APK 后，从应用图标进入。后续更新保留同一应用包名 `local.acgnhub.mobile` 和签名身份；卸载会移除应用私有资料及下载，重要成品应先导出。Windows 与 Android 不自动同步收藏、文件或阅读进度。

## 作品与资源

首页按动画、漫画、轻小说与 Galgame 分别展示作品。动画季度按本地年份和月份计算；Bangumi 与 VNDB 提供作品资料，下载能力仍由具体资源来源决定。

在「来源管理」启用需要的来源，再从作品详情或「找资源」检索。预置下载来源默认关闭。先核对作品版本、语言与章节，再开始下载。作品资料存在、来源健康检查通过或目录能够打开，都不代表每个文件均可下载。

小说沿用 LNovel 可读取文本生成 UTF-8 TXT，漫画按来源可读取的章节原图生成 CBZ。TXT 不含原书插图；读取不完整或身份不符会报错。《无职转生》正篇与蛇足篇分别保留，上游正文限制见[核查记录](../research/lnovel-main-series-v040.md)。本版没有新增菠萝包来源。

## 两个平台的下载能力

| 操作 | Windows | Android |
| --- | --- | --- |
| 普通 HTTP / HTTPS 文件 | 内置 aria2；可暂停、续传、限速 | 原生前台 HTTP 引擎；提供暂停、续传、限速与取消 |
| 漫画原图转 CBZ | 支持来源允许读取的章节 | 支持，触屏翻页及已下载文件内读 |
| 轻小说正文转 TXT | 支持来源允许读取的分卷 | 支持，目录、进度与同作品卷间切换 |
| 磁力、Torrent、qBittorrent | 按内置或外部引擎设置处理 | 不支持；对应操作提示需电脑版 |
| Python / JMComic / yt-dlp / FFmpeg | 可选，需要对应本机工具 | 不支持 |
| Galgame 归档文件 | 按来源获取文件直链 | 仅普通 HTTP 文件；网页和网盘按原站流程处理 |
| Windows 游戏扫描、启动、存档工具 | 对应本地工具流程 | 不支持 |

Android HTTP 引擎最多同时运行 3 个任务，单文件上限 64 GiB；实际容量受设备可用空间限制。断点续传需要服务器正确支持 Range 等条件，不能保证所有链接都可续传。下载地址失效、需要登录或来源验证时，应先回来源确认，不将网页当作文件成功保存。

Android 下载要求应用继续运行。当前没有系统前台服务，不承诺锁屏或切到后台后持续传输；系统结束进程后，应用重启会将未完成的原生 HTTP 任务恢复为暂停，需手动继续。漫画与小说下载流程不等于原生 HTTP 引擎任务，其故障或中断按各自界面处理，不承诺逐页或逐章跨进程续传。

下载完成后，成品按作品与单元登记，支持应用内观看的格式会出现阅读入口。单纯列出 Galgame 文件或对归档进行部分传输，不代表已经验证完整游戏下载、解压、安装与运行。

## 手机上阅读与存储

Android 使用应用私有资料目录，默认下载文件放在其中的 `Files`。这些目录不等同于手机公共「下载」目录，也不能直接套用 Windows 的盘符或便携 `Data` 路径。Windows 便携模式不适用于 Android。

手机主要入口放在底部导航，其余操作由「更多」打开。漫画支持连续长条滚动、单页、全屏及单页触屏翻页；小说提供章节目录、字号、行距、纸色与阅读进度。接续下一话 / 卷只使用同作品、同版本且已经完成的本地文件，不会自动下载缺少的章节。

CBZ 与 TXT 使用应用内置阅读器。本地视频是否可播放取决于 Android WebView 和系统编码。EPUB / PDF 不由内置阅读器打开，需导出后交给适合的应用。

在「下载」找到已完成的任务，点击「导出 / 分享」，通过 Android 系统选择器将单个成品交给所选应用。多文件任务先选择一个成品。系统可提供的保存位置或接收应用取决于手机已安装的工具；取消选择器会回到应用。只有用户选择目标后才会交出文件，应用不自动选择接收方或发送。此操作不导出整个私有资料库，任务、收藏和阅读进度仍留在当前安装中。

## 开发构建

前端和原生构建版本统一为 0.5.0。正常开发检查：

```powershell
npm ci
npm run verify
npm run test:e2e
powershell -NoProfile -File .\src-tauri\scripts\build-desktop.ps1 -Action test
```

Windows EXE 与 NSIS：

```powershell
powershell -NoProfile -File .\src-tauri\scripts\build-desktop.ps1 -Action bundle
```

Android 本轮使用 JDK 17、Android SDK Platform 36、NDK 28.2.13676358、Gradle Wrapper 8.14.3 与 Android Gradle Plugin 8.11.0。SDK、NDK、Java 的路径来自 `ANDROID_HOME`、`NDK_HOME`、`JAVA_HOME`，不要把个人机器路径写入提交文件。Rust 需安装 `aarch64-linux-android`、`x86_64-linux-android` 目标。Windows 主机还需要 MSVC Build Tools 和 Windows SDK，以构建 Rust 主机工具。

```powershell
powershell -NoProfile -File .\src-tauri\scripts\build-android.ps1 -Action info
powershell -NoProfile -File .\src-tauri\scripts\build-android.ps1 -Action build
```

脚本默认构建两种 64 位 ABI，校验并复制原生库到 JNI 目录，再封装通用 Release APK。Windows 没有符号链接权限时也可以使用此默认路径，无需改变系统安全策略。`-PackageOnly` 仅用于重新封装已经校验的 JNI 库；修改 Rust 或前端后必须重新完整构建，不能把旧库作为新实现发布。

未签名 APK 通常位于 `src-tauri/gen/android/app/build/outputs/apk/universal/release/`，以实际 Gradle 输出为准。签名时传入实际输入文件：

```powershell
powershell -NoProfile -File .\scripts\sign-android-apk.ps1 `
  -InputApk '<实际未签名APK路径>' `
  -OutputApk '.\release\v0.5.0\ACGN-Hub-0.5.0-android-64bit.apk'
```

签名脚本使用独立的本地 `.local/android-signing` 目录，并验证 APK 签名及 ZIP 对齐。首次生成的签名材料应私下备份，用于以后应用更新；仓库和发布附件不包含私钥、口令、用户数据库、设备资料与媒体。发布前仍需检查两种 ABI、版本号、签名、安装启动与实际下载行为，签名成功不能代替运行验收。

## 准备发布附件

`scripts/package-verified-release.ps1` 负责 Windows EXE、NSIS 与便携支持文件，依据当前扫描回执生成 Windows 的 `VERSION.json` 和 `SHA256SUMS.txt`；它不自动构建便携 ZIP，也不将 Android APK 纳入校验清单。Android 须单独签名、执行 `scripts/verify-android-apk.py` 并完成原生运行验收。签名脚本拒绝覆盖已存在输出；保留旧候选后再输出新文件，避免将相同版本名下的旧包误当修复版。

完成 Windows 包装与便携 ZIP、放入已签名且验收通过的 APK 后，运行独立清单脚本：

```powershell
python .\scripts\create-crossplatform-manifest.py .\release\v0.5.0 `
  --apk-receipt '.\.work\android-v050\<最终APK校验回执>.json'
```

它只接受本仓库 `release/v<版本>`，要求 EXE、x64 setup、Windows x64 portable ZIP、Android 64bit APK 四个准确文件名齐全，生成独立的 `RELEASE-ASSETS.json` 与 `CHECKSUMS-SHA256.txt`，保留 Windows 的 `VERSION.json` 和 `SHA256SUMS.txt`。可省略 `--apk-receipt`，但正式发布应传入对应最终 APK 的校验回执，核对签名检查与字节身份。清单只记录公开文件名、大小、SHA256 和平台，不嵌入本机路径或用户资料；生成成功也不代替原生运行验收。

最终发布按明确文件名单选取这四个产物和配套说明，分别核对文件名、字节数与 SHA256。便携 ZIP 只放入可分发程序与支持文件，不递归打包工作区或含有 `Data` 的个人便携目录。修改任何附件后重新生成综合清单；将附件传到 GitHub 后重新下载并核对 SHA256，发布说明只引用这组字节身份。候选包的静态回执不替代最终包的检查。

## 验证范围

最终前端单测 670 项、Rust 回归 109 项（另 2 项默认忽略）通过；最近完整浏览器交互 91 项通过，最后任务可选状态与管理器测试补充没有改变布局。本轮原用户数据 9 表、3 个媒体及 22 个旧 EXE 复核保持，数据库完整性 ok；类型检查与各轮源码适用范围见验证记录。

最终 Android APK 以 64 KiB/s 下载约 4.2 MB 的 Project Gutenberg `pg10.txt`：约 2.3 MB 时暂停、结束进程、冷启动仍为暂停，再继续到完成，并实际打开正文和系统选择器后取消。另重新下载《文学少女》第二卷 12 / 12 并阅读、前后卷切换，保留第一卷章节及已有漫画第 3 页。此前阶段包已下载首卷和一话 21 页 CBZ、实际全屏长滚 / 触屏翻页，并打开 TXT / CBZ 系统选择器取消。最终 Windows 程序实际读取既有两卷 TXT 和漫画记录，恢复章节及漫画第 2 页，正常退出；未将阶段下载冒充最终程序重下。

Android 使用独立 API 35 模拟器、普通 ADB / UIAutomator，Windows 使用独立资料库与 UIAutomation；未用 CDP 或脚本注入。源码回归、真实来源下载与各阶段构建分别记录，细节见[本版验证记录](../research/android-v050.md)。系统选择器只验证打开与取消，没有向任何接收方发送文件，也不据此宣称已写入公共下载目录。

真实物理 Android 手机、全部 API 26+ 系统、所有视频编码、持续后台下载、完整 Galgame 安装运行及 Windows / Android 自动同步均不属于现有验收结论。后续测试只按实际样本记录，不把旧版本结果直接当成本版通过。详见 [VERIFICATION.md](../../VERIFICATION.md) 与 [第三方声明](../../THIRD_PARTY_NOTICES.md)。
