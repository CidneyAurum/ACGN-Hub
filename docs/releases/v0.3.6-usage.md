# ACGN Hub 0.3.6

Windows x64 · 下载后直接在应用内阅读漫画、小说及播放视频。发布包不含用户资料或媒体。

## 启动与升级

解压便携 ZIP 后，双击 `START-PORTABLE.cmd`，使用本目录自己的 `Data`；直接双击 EXE 使用系统默认资料目录。需要 Microsoft Edge WebView2 Runtime。

本机桌面升级入口继续使用原 `D:\ACGN\release\v0.3.2\Data`，保留现有配置、下载与收藏。不要同时运行两个实例写同一资料库。旧版本与旧 Data 保留。安装包单独提供；本轮只验证便携程序，未实际安装 NSIS。

## 下载后应用内观看

- 在“下载”中找到已完成的任务，点击 **阅读漫画**、**阅读小说** 或 **应用内播放**。多文件任务先选择一个实际成品。
- 漫画仍保存为 CBZ，阅读器直接读取其中页图，无需解压或转换。默认 **连续滚动**，向下阅读整章；也可切换 **单页翻页**，使用上一页/下一页、输入页码、左右键及 Home/End。支持适合宽度/高度、浅深舞台与全屏。全屏内保留工具栏、翻页和跳页控件，单页模式还提供左右悬浮按钮。只在当前页成功加载后保存页码，下次打开继续读。
- 小说支持 UTF-8 TXT（含 BOM），可调字号并保存阅读位置。正文按纯文本显示。其它编码需先转为 UTF-8，EPUB/PDF 继续使用系统阅读器。
- 视频使用内置视频控件，支持音量、进度、全屏和播放位置记忆。HEVC、部分 MKV/AVI/TS 及内嵌字幕是否可播放取决于系统解码能力；失败时点击 **使用系统播放器**。不承诺所有格式均能内置播放。
- 从来源详情或“漫画打包”完成下载后，也会出现立即阅读/播放入口；不会强制打断当前操作跳页。

下载中心新增“按作品观看”，将有可靠作品身份的已完成话、集、卷整理成目录。阅读器提供作品章节目录、上一话/下一话和可关闭的自动接续；连续阅读到底后会显示 3 秒倒计时，可取消。自动接续不会下载新章节，也不会跨作品、季度或漫画版本。

轻小说阅读器会识别正文里的章节标题，支持本卷目录跳转、字号、行距、米白/护眼/夜间纸色和阅读宽度；正文始终按纯文本显示，不执行文件里的 HTML。

## 版本选择与作者搜索

同名漫画的不同改编版保留独立来源 ID、作者及章节目录。在作品资源处使用“作品 / 改编版本”选择版本；例如《安达与岛村》的まに版与柚原もけ版分别列出，不再只取搜索首项。新下载按来源版本分目录，避免同名第 1 话冲突，已有文件不会自动移动。

统一搜索框同时支持作品名和作者名：输入作者姓名或可靠别名时，直接显示其实际关联作品与参与角色，无需先打开人物页面；同名作者可用简短筛选切换。当前 Galgame 作者关联检索未接入。

“系统程序打开”与原“打开文件”入口保留。阅读时原文件以只读方式打开，返回下载中心后释放；如需移动、改名或删除正在阅读的文件，请先退出阅读页。

## 文件与阅读记录

阅读不会修改 CBZ、图片或视频内容，不会降低画质。进度以文件路径、大小和修改时间区分；同路径替换文件后不会误用旧位置。存储不足无法保存进度时会提示，仍可继续阅读。

漫画上限 1000 页、单页 50 MiB、整章解压后 500 MiB；不支持加密、分卷或 ZIP64 归档。TXT 上限 20 MiB。原文件损坏、移动或不在当前已完成任务中时会明确报错，不自动重新下载。

季度发现、Bangumi 漫画与轻小说推荐、原图漫画下载、小说 TXT、完成后命名、BT 恢复与来源排序均保留。WeebCentral 和快看保持撤下，原来源地址与启用状态保留。
