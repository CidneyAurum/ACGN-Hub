# ACGN Hub 0.4.0 使用指南

本版重点补齐轻小说与 Galgame 资源流程，并改善 Windows 便携包在移动目录、换盘和升级时的资料保留。动画、漫画、收藏、下载命名及内置阅读继续使用原有流程。

## 首次使用

从 [GitHub Releases](https://github.com/CidneyAurum/ACGN-Hub/releases/latest) 下载 Windows x64 便携 ZIP，完整解压到有写入权限的目录，再运行 `START-PORTABLE.cmd`。不要直接在压缩包预览中运行程序。

便携包中的 `ACGN-HUB-PORTABLE` 是模式标记，保留它后，双击同目录的 `ACGN-Hub-0.4.0.exe` 也会使用同一个 `Data`。只复制 EXE 不会带走资料与便携标记。Microsoft Edge WebView2 Runtime 仍是系统前提；其它系统或架构没有正式验证。

1. 打开「设置」，检查待整理、作品库、电子书输出和存档备份目录。便携包默认将它们放在 `Data\Files` 下。
2. 打开「来源管理」，启用需要的来源。预置来源默认关闭；已有用户的地址、令牌及启用状态保留。
3. 从发现页选择作品，或者在「找资源」按作品名、作者名或来源支持的完整作品链接搜索。先确认作品版本，再选择章节、卷或文件。

普通 HTTP、磁力和 Torrent 使用内置 aria2，无需另装下载器。qBittorrent 是可选方式，需要启用其本机 Web UI。可选 JMComic 依赖本机 Python / jmcomic；公开投稿下载依赖本机 Python、yt-dlp 与 FFmpeg。没有用到这些功能时无需安装这些工具。

## 轻小说来源

### 首页先显示已有内容

轻小说发现首页先显示首批 8 部真实作品，再补齐本页 24 部。过期缓存先显示，推荐在后台更新；后续请求失败时保留已显示结果，可点「补全本页」重试补齐当前页。首页作品资料来自 Bangumi，下载是否可用需在具体来源里单独确认。

### LNovel：日轻中文文本

适合从来源现有目录查找日轻中文分卷。输入作品名或明确的作者名后，选择匹配作品并查看实际分卷。0.4.0 改善标题、作者和别名匹配，以及 HTML 实体、段落、插图条目与资源 ID 的处理。

分卷下载生成 UTF-8 TXT，不含原书插图。图片专用条目不会被当成可读正文；读取失败或目录身份不匹配会明确报错，避免将网页、错误响应或其它作品写成小说。可用卷数以来源当前目录为准。

来源缓存目录不能当作完整日轻书库。没有匹配或只找到衍生作品时，会补查官方月 / 周索引，按作品 ID 合并去重；也可填写来源支持的完整作品链接或站点 ID。上游是否仍能获取该作品及最新分卷，以实际结果为准。来源要求原站验证或结构变化时会显示错误，健康检查通过也只表示相应目录可读取。

《无职转生》正篇 2013《到了异世界就拿出真本事》与蛇足篇 4325 独立保留，不再用蛇足篇代替正篇搜索结果。当前实测正篇详情 API 返回 HTTP 408，首章错误响应明确表示下架；原站正文也有截断和加载失败提示。本轮未取得正篇完整首卷，搜索可见不代表当前可下载。详情见[正篇核查记录](https://github.com/CidneyAurum/ACGN-Hub/blob/main/docs/research/lnovel-main-series-v040.md)。

## Galgame 资源选择

Galgame 发现页使用 VNDB 作品资料；下载入口可以跨已启用来源检索。建议先筛选「中文」「Windows」「本体」，再确认版本、语言证据和获取方式。

| 入口 | 适合做什么 | 操作方式 |
| --- | --- | --- |
| 真红小站 | 查中文目录及原文合集中的游戏文件 | 文件直链加入内置下载 |
| ShionLib | 比较汉化组、版本、平台、文件与哈希信息 | 依原站条件完成验证、获取链接 |
| 鲲 Galgame | 补充不同平台和社区发布的资源 | 先核对发布说明，网页或网盘在浏览器中处理 |
| VNDB 官方发行 | 查官方商店、试玩、官网及免费发行参考 | 打开对应页面，按发行方流程获取 |

本版扩展真红原文合集的可识别文件，改善 KUN、ShionLib 等来源的匹配、分页和取消处理。中文 Windows 版本保持优先；目录中的日文、未知语言或部分汉化条目保留其真实标签。不要仅根据中文作品名判断文件语言。

分卷档案应全部下载到同一版本目录，并保留原文件名。补丁、试玩、存档、原声与工具会分别标注；它们不能代替完整游戏。下载归档后需要自行解压和核对，再添加到「Galgame 工具」扫描启动文件、选择入口和备份存档。程序不会自动解压或运行下载的游戏。

现有真实验证包含来源目录、文件头、部分传输及暂停续传样本；尚未完成完整 Galgame 下载、安装及运行验收。

## 下载后阅读与观看

在「下载」中找到已完成记录，选择「应用内观看」或相应阅读入口。同作品的多话、多卷、多集会归在一起；自动接续仅使用同作品、同版本已经完成的本地文件。

- **CBZ 漫画**：默认连续滚动，可切换单页；全屏仍提供翻页、页码和工具栏。保留阅读位置。
- **TXT 小说**：提供章节目录、字号、行距、阅读宽度和纸色，重开后恢复进度。
- **视频**：使用系统 WebView2 支持的编码，可保存播放位置；系统默认程序仍可使用。
- **EPUB / PDF**：交给系统已安装的阅读器，当前内置阅读器不处理这两种格式。

文件成功生成后再登记成品。若资料保存失败，先使用页面上的重试保存或导出记录功能保留本次窗口中的结果，再退出。不要仅因进度写入失败重复下载已有成品。

## 迁移与升级

### 整个便携目录搬家

1. 完全退出应用，等待下载引擎和 WebView2 随之退出。
2. 备份旧便携目录，将包含程序、模式标记和 `Data` 的整个目录复制到新位置或另一台 Windows x64 电脑。
3. 启动新位置中的 `START-PORTABLE.cmd`，或保留便携标记的 EXE。
4. 核对设置、已完成文件和阅读进度，再继续下载。移动后的活动 aria2 任务先暂停，旧断点控制文件保留，确认目录后手动续传。

`Data` 包含 SQLite、WebView2 设置与阅读记录、内置引擎运行文件、默认媒体目录及其它应用缓存。迁移会更新原 `Data` 根目录内已登记的路径；它不会搬运或删除媒体文件。

在 `Data` 外自行设置的下载、书库和游戏路径仍保持原值，需自行搬迁、重新挂载或在设置中调整；改设置本身不会移动文件。qBittorrent 属于外部客户端，其任务关联仍需在该客户端核对。换机后的连接凭据及第三方登录可能需要重新输入。

### 从旧版升级

1. 关闭旧版并备份原始资料。保留旧程序，便于核对。
2. 将新版 ZIP 解压到一个独立目录。
3. 在首次启动前，将实际使用的旧 `Data` 完整复制到新目录。若目标已有 `Data`，先保留该目录，不把两个资料库合并覆盖。
4. 启动新版并检查保存目录。已有便携身份记录会用于更新内部路径；旧版没有记录时，仅在至少两个默认目录指向同一个旧资料根目录时自动识别，无法确定的外部路径不猜测替换。

一直通过自定义 `ACGN_HUB_DATA_DIR` 或已有升级脚本启动的用户，应继续指向实际旧资料库。这个环境变量接受不含 `..` 的绝对路径，并优先于同目录便携标记。不要同时运行两个实例写同一个资料库。

如果存在未恢复的文件改名记录，请将完整便携目录放回原位置，启动并完成恢复后再移动；程序会阻止不确定的路径迁移，保留原文件与记录。新旧资料目录也不要相互嵌套。

### U 盘与文件系统

0.4.0 的 Windows 成品发布改为同卷、无覆盖的原子移动，避免依赖仅部分文件系统支持的硬链接。代码路径适用于 NTFS 及 exFAT / FAT32；本次没有真实 exFAT / FAT32 设备验收。FAT32 仍受单文件 4 GiB 限制，大型视频和游戏档案建议使用 NTFS 或 exFAT。

备份和复制期间保留足够剩余空间。不要拔出仍在写入的移动存储。

## 常见情况

| 现象 | 处理方式 |
| --- | --- |
| EXE 启动后像是空资料库 | 确认是否完整解压、是否带便携标记，以及正在使用哪个 `Data`；先找到旧资料再继续 |
| 换盘后外部书库找不到文件 | 该目录不在便携 `Data` 中，确认新盘符并在设置中调整，或重新扫描 |
| 来源没有结果 | 检查是否启用；尝试来源支持的别名或完整作品链接，确认原站是否收录该作品 |
| 只有网页入口 | 用浏览器按原站流程获取文件；分享页、商店页不是直链 |
| BT 速度为零 | 在下载任务中检查节点、阶段和错误；目录新不等于当前有可连接节点 |
| 小说分卷或章节不完整 | 刷新目录并核对来源实际收录；正文读取失败不会写出伪完成成品，TXT 不含插图 |
| 已完成文件打不开 | 检查文件是否仍在登记位置、格式与系统编码支持；可选择系统默认程序 |
