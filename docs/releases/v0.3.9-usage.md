# ACGN Hub 0.3.9 · 暖色电视图标

软件图标、窗口图标、侧栏标识与浏览器图标统一为暖粉紫小电视：奶白屏幕、圆角边框和轻微笑脸。ICO 包含 16、24、32、48、64、128、256 像素，适配任务栏与高 DPI 桌面。站内图标增加独立缓存标识，升级后重新打开程序即可加载新版。

使用桌面快捷方式启动 0.3.9，继续沿用原 release/v0.3.2/Data；旧版本保留。便携包内 START-PORTABLE.cmd 使用其自身独立 Data，勿覆盖已有资料目录。

本版是视觉更新，保留 0.3.8 的真红文件下载、ShionLib 多版本目录、跨源检索、Galgame 组合筛选、分卷与版本目录功能，以及漫画／小说内置阅读器。相关操作见 docs/releases/v0.3.8-usage.md 与 v0.3.6-usage.md。

本轮核对图标多尺寸、透明通道、SVG 一致性、页面显示、生产构建及桌面图标。安装包构建并扫描，未实际安装；不将此前功能测试算成本次重新运行。
