- Bangumi / VNDB 用于作品资料；“找资源”也能直接查来源，不要求先在元数据站点找到条目。
- 小说、漫画先确认来源中的准确作品，再列分卷或章节；同人、插画集、续季、片段和合集有提示。
- B 站公开投稿来源默认停用，由用户主动启用；已实现完整 BV 投稿 URL 解析和下载。本机匿名关键词搜索当前被 HTTP 412 / 验证码限制，不能宣称输入片名即可自动搜通。候选会显示上传者、时长与片段/合集提示，具体投稿经实际解析后才提供 MP4 下载。
- 普通 HTTP 交给 aria2；BT 默认配置为内置 aria2，qBittorrent 是可选引擎。Torrent 元数据任务需要继续跟随内容任务，不能把保存了 `.torrent` 当作视频下载完成。

## 公开投稿下载的实际限制

仅支持 `bilibili.com/video/BV…` 普通公开投稿及有效分 P。没有 Cookie、浏览器资料读取、账号登录、付费番剧或 DRM 处理。

下载优先选择公开可读取的较高画质（默认上限 1080p），再合并为 MP4，并显示实际选中的分辨率。搜索标题写有“1080p”，或解析结果列出 1080p 格式，都不构成当前下载画质承诺。请求采用 1 MiB HTTP 分段、25 秒网络超时与 5 次重试。针对实际分段中断，已加入同任务暂存续传与最多 3 次有限恢复（首次加恢复最多 4 轮，总处理上限 30 分钟）；403/412/429 不做自动再解析。恢复机制通过本地真实 yt-dlp Range 回归，包含该机制的最终构建也已在正常 UI 中完成公网目标整集。

这是可选本机工具桥接，要求 PATH 中可用的 Python，以及已安装的 `yt-dlp` 和 FFmpeg（也可由已安装的 `imageio-ffmpeg` 包提供）。不会自动下载未知可执行程序。本机已核验版本为 Python 3.12.6、yt-dlp 2026.7.4、imageio-ffmpeg 0.6.0 / FFmpeg 7.1。其它机器需单独检查环境；可选依赖安装命令为：

```powershell
python -m pip install yt-dlp imageio-ffmpeg
```

原生桥接已实现进度、取消、自有临时目录和不覆盖发布；对应局部测试通过，公开投稿整集 App 下载及成品解码现已在正常 UI 中验证。
